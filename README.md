## 프로젝트 목표

이 프로젝트는 파일 디스크립터에서 한 줄을 읽어오는 함수를 만드는 것입니다.

## 필수 파트

* 함수 이름: `get_next_line`
* 프로토타입: `char *get_next_line(int fd);`
* 제출 파일: `get_next_line.c`, `get_next_line_utils.c`, `get_next_line.h`
* 매개변수: `fd`: 읽을 파일 디스크립터
* 반환 값:
    * 읽은 줄: 올바른 동작
    * NULL: 더 이상 읽을 내용이 없거나 오류가 발생했습니다.
* 사용된 외부 함수: `read`, `malloc`, `free`
* 설명: 파일 디스크립터에서 읽은 줄을 반환하는 함수를 작성하세요.

* `get_next_line()` 함수를 반복적으로 호출하면 (예: 루프 사용) 파일 디스크립터가 가리키는 텍스트 파일을 한 번에 한 줄씩 읽을 수 있어야 합니다.
* 여러분의 함수는 읽은 줄을 반환해야 합니다. 더 이상 읽을 내용이 없거나 오류가 발생하면 NULL을 반환해야 합니다.
* 파일을 읽을 때와 표준 입력에서 읽을 때 모두 함수가 예상대로 작동하는지 확인하세요.
* 반환되는 줄은 파일의 끝에 도달하여 `\n` 문자로 끝나지 않는 경우를 제외하고는 줄바꿈 문자인 `\n`을 포함해야 합니다.
* 여러분의 헤더 파일 `get_next_line.h`는 최소한 `get_next_line()` 함수의 프로토타입을 포함해야 합니다.
* 필요한 모든 도우미 함수를 `get_next_line_utils.c` 파일에 추가해야 합니다.
* `get_next_line()`에서 파일을 읽어야 하므로, 컴파일러 호출에 다음 옵션을 추가해야 합니다: `-D BUFFER_SIZE=n`  
    이것은 `read()`의 버퍼 크기를 정의합니다. </br>
    일반 플래그 외에도 `-D BUFFER_SIZE` 플래그의 유무에 관계없이 이 프로젝트를 컴파일할 수 있어야 합니다.
* 다음과 같이 코드를 컴파일합니다 (버퍼 크기 42가 예시로 사용됨):  
    `cc -Wall -Wextra -Werror -D BUFFER_SIZE=42 <files>.c`
* `read()`가 파일의 끝에 도달하지 않은 상태에서 파일 디스크립터가 가리키는 파일이 마지막 호출 이후 변경된 경우 `get_next_line()`은 정의되지 않은 동작을 하는 것으로 간주합니다.
* 또한, `get_next_line()`은 바이너리 파일을 읽을 때 정의되지 않은 동작을 하는 것으로 간주합니다.

* 금지 사항:
    * `lseek()`는 금지되어 있습니다.
    * 전역 변수는 금지되어 있습니다.

## 보너스 파트

* 보너스 파트 요구 사항은 다음과 같습니다:
    * 단 하나의 정적 변수만 사용하여 `get_next_line()`을 개발하세요.
    * 여러분의 `get_next_line()`은 동시에 여러 파일 디스크립터를 관리할 수 있습니다.  
        예를 들어, 파일 디스크립터 3, 4 및 5에서 읽을 수 있다면, 각 파일 디스크립터의 읽기 스레드를 잃거나 다른 fd에서 줄을 반환하지 않고 호출당 다른 fd에서 읽을 수 있어야 합니다.  
        즉, fd 3에서 읽기 위해 `get_next_line()`을 호출한 다음, fd 4, 그 다음 5, 그런 다음 다시 3, 다시 4 등을 호출할 수 있어야 합니다.
    * 보너스 파트 파일에 `_bonus. [c\h]` 접미사를 붙이세요.  
        즉, 필수 파트 파일 외에도 다음 3개의 파일을 제출하게 됩니다:  
        `get_next_line_bonus.c`  
        `get_next_line_bonus.h`  
        `get_next_line_utils_bonus.c`

## 사용 방법

1.  **컴파일:**
    * 필수 파트만 컴파일하는 경우:  
        `cc -Wall -Wextra -Werror -D BUFFER_SIZE=<원하는_버퍼_크기> get_next_line.c get_next_line_utils.c -o get_next_line`
    * 보너스 파트도 컴파일하는 경우 (필수 파트 파일과 보너스 파트 파일을 모두 포함):  
        `cc -Wall -Wextra -Werror -D BUFFER_SIZE=<원하는_버퍼_크기> get_next_line.c get_next_line_utils.c get_next_line_bonus.c get_next_line_utils_bonus.c -o get_next_line`
2.  **실행:** `./get_next_line <파일_이름>`  
    또는 표준 입력에서 읽으려면 파일 이름을 생략합니다.
3.  **함수 사용:** * `get_next_line` 함수를 호출하여 파일 디스크립터에서 한 줄을 읽습니다.
    * 반환 값은 읽은 줄이거나, 더 이상 읽을 내용이 없거나 오류가 발생한 경우 `NULL`입니다.
    * (보너스) 여러 파일 디스크립터를 사용하는 경우, `get_next_line`을 반복적으로 호출하여 각 파일에서 번갈아 가며 읽을 수 있습니다.
